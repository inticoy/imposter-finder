# 버전별 스펙

| 버전 | 상태 | 한 줄 요약 |
|---|---|---|
| v1 | 종료 | GitHub Actions에서 PUBG 그룹 매치 범인찾기 |
| v2 | 종료 (2026-10-10) | 맥 상주 봇: `/user` 전적 감정서 + 15분 수집 + SQLite |
| v3 | **운영 중 / 확장 중** | PUBG·FC·롤 이미지 리포트 운영, 영입 알림·`@멘션` 자연어 계획 |
| v4 | **운영 중** (2026-10-10~) | 맥 상주 대신 GitHub Actions + cron-job.org 15분 수집 (`/user`는 코드만 유지) |

v3는 리포트 기능, v4는 실행 환경이라 함께 운영 중입니다.

## v1 — GitHub Actions (2026-05 ~ 08)

- cron-job.org가 30분마다 workflow를 실행, 새 매치를 분석해 Discord에 올리고 `data/seen_matches.json`을 커밋
- **종료 사유:** `/user` 같은 슬래시 명령은 봇이 계속 켜져 있어야 해서 맥 상주로 이전 (2026-08-11). PUBG API 차단 문제는 없었음
- 워크플로는 2026-10-09에 삭제. cron-job.org에 남은 작업이 있으면 꺼야 합니다

## v2 — 맥 상주 봇 (2026-08 ~ 10-10)

- `serve` 하나로 슬래시 명령 봇과 15분 수집 루프 실행, 매치·연결 기록은 SQLite
- `/user`: 6개 지표 + 등급 + 방사형 그래프
- 재시작 때 꺼져 있던 동안의 매치도 리포트 (2026-08-16)
- Python 3.9(Xcode) → 3.14(Homebrew), 로그 `logs/`로 이동 (2026-10-09)
- **종료 사유:** `/user`를 쓰지 않게 되어 상주할 이유가 없어짐. 맥이 꺼져 있으면 수집도 멈춤 → v4로 이전. `serve`와 launchd plist는 예비로 남김 (`launchctl disable`로 꺼 둠)
- 자세한 내용: [how-it-works.md](how-it-works.md)

## v3 — 게임별 이미지 리포트 (운영 중)

같은 레포에 FC 모듈을 두고, 결과는 FC thread로 보냅니다. 기능이 커지면 레포를 나눕니다.

- **FC 운영 (2026-10-09~):** 15분마다 친구전 리포트 — 스코어·맞대결 10경기·⭐ MVP·🔎 범인·스탯 그래프·Gemini 한 줄 평가, 몰수 경기 한 줄
- **롤 운영 (2026-10-10~):** 친구 계정 교집합으로 친구전을 찾아 이미지 4장(결과·선수·오브젝트·골드 차이) + 총평/평가 + OP.GG 경기 버튼. 패배 경기 최고 친구는 ACE
- **PUBG 이미지 리포트 (2026-10-10~):** 배틀로얄은 결과·스쿼드 기록·이동 경로·교전 흐름·쓴 무기, TDM은 라운드 결과·팀별 기록·쓴 무기. TDM 승리 팀 MVP·패배 팀 ACE·별도 범인
- **FC 이미지 리포트 (2026-10-10~):** 축구 중계식 이미지 5장(스코어보드·MVP/범인·경기 기록·슈팅맵·라인업), 팀컬러 엠블럼·구단 가치·시즌 얼굴
- **GIF 카드 (2026-10-10~):** 배그 이동 경로·교전 흐름, 롤 골드 차이를 시간 흐름 GIF로 (장면 0.42초, 마지막 1.8초, 공통 팔레트로 수백 KB)
- 공통: 이미지 로컬 영구 캐시(`data/assets/`), 평가는 해설자 말투 한 줄 52자 이내, 모든 리포트 @silent·DM 없음
- 동작은 [how-it-works.md](how-it-works.md)
- **다음 후보**
  - 영입·강화 알림: 이적시장 거래 기록 API + 경기 스쿼드 비교 ("건우가 손흥민 TK 🥇+8 영입")
  - 스쿼드 보기: 최근 경기 18명으로 재구성, 미니페이스온·오버롤
  - 선수 정보·추천: 데이터센터 능력치·특성, 시즌·강화별 비교
  - `@멘션` 자연어: 살래말래처럼 "나랑 성현 전적", "건우 스쿼드 보여줘"
- 데이터 출처와 지켜야 할 규칙: [fc-online.md](fc-online.md)

## v4 — GitHub Actions + cron-job.org (2026-10-10~, 운영 중)

- cron-job.org가 15분마다 `find-imposter.yml`을 `workflow_dispatch`로 실행 → `collect`가 배그·FC·롤을 한 번씩 수집·리포트
- v1과 달리 상태를 커밋하지 않음: SQLite DB·FC 메타는 Actions 캐시에 매 실행 저장·복원, 이미지 캐시는 바뀔 때만. 캐시가 없으면 기록만 해 중복 없음
- `concurrency`로 한 번에 하나, 공개 로그에서 `players.json`의 이름·닉네임·ID를 `***`로
- 맥 시스템 글꼴 대신 레포의 Pretendard·Teko (리눅스에서도 같은 이미지)
- public 레포라 Actions 시간 한도 없음. v1의 30분 주기는 cron-job.org 한도가 아니었던 것으로 보임 (작업당 1분 간격까지 가능)
- 설정과 확인 방법: [README](../README.md#자동-실행-github-actions--cron-joborg--운영-중)
